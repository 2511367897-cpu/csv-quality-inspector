# CSV Quality Inspector

## 解决什么问题
检查 CSV 数据中的空字符串、重复记录、首列重复值和列数异常，帮助发现数据质量问题。

## 运行前后差别
运行前只有原始 CSV；运行后终端显示检查报告和文件行号。工具只读取文件，不产生清洗后的数据文件，也不修改原件。 `examples/sample_output.csv` 是示例副本，并非工具生成的清洗结果。

## 怎么安装运行
需要 Python 3，无需安装第三方包：`python3 check_csv.py examples/sample_input.csv`。

## 支持与不支持
支持 UTF-8（含 BOM）和可严格往返的 GB18030 CSV、空字符串缺失统计、完全重复行、第一列重复的不同值和列数异常。数据行数不含表头；短行缺少的字段计入坏行，不作为空字符串计数。空白行也计为数据行；最多列出 10 个行号。第一列重复的统计值为重复的不同值数量。空白字符不会被视为空字符串。按 UTF-8 优先、再尝试 GB18030；无法确定编码或含异常控制字符时停止。编码判断并非万能。 不支持数据清洗、规则配置、生成输出 CSV 或图形界面；不校验日期或数字格式。
